Overview

The Stream Den API exposes live sports channels as JSON. Every endpoint returns data with CORS enabled, so you can call it straight from a web page, app, or script. Data is refreshed automatically, and live channels are sorted to the front of every listing.

Public Free, ad-supported

Anybody can use the public API with no key. Streams are served through an embedded player that includes ads, which keeps the service free to run.

Private Ad-free

For apps and integrations that need ad-free playback and higher limits. Access is granted on request — see Getting access.

Public API

No key required. Requests are rate-limited per IP to keep things fair — if you hit the limit, back off and retry.

GET /api/v1/sports ▼

List every sport that currently has streams, with the number of available channels in each.

# Example
curl "{{ base_url }}/api/v1/sports"
FieldTypeDescription
sportsarrayEach item: sport (name) and count (live channels available)
total_streamsnumberTotal channels across all sports
GET /api/v1/channels ▼

Search and filter the full channel list. Results are sorted with live games first.

# Example: soccer streams, page 2
curl "{{ base_url }}/api/v1/channels?sport=soccer&page=2&per_page=30"
ParamTypeDescription
qstringFree-text search across team names, tournaments, and sports
sportstringFilter by sport (e.g. soccer, basketball)
sourcestringFilter by provider/source
liveboolPass 1 to only show live channels, 0 for non-live
pagenumberPage number, starts at 1
per_pagenumberResults per page (default 30, max 100)
Response fieldDescription
channelsArray of channel objects (see below)
total / page / per_page / pagesPagination metadata

Channel object fields: id, slug, sport, tournament, matchup, source, is_live, time, time_unix, home_team, away_team, home_abbr, away_abbr, game_status.

GET /api/v1/channels/{id} ▼

Get one channel by its numeric ID, including its available streams and the player page URL.

# Example
curl "{{ base_url }}/api/v1/channels/42"

Returns {"channel": {...}} with an extra play_url and streams[] array. Each stream has label, embed_url, and watch_url. Returns 404 if the ID doesn't exist.

GET /api/v1/play/{id} ▼

Get a ready-to-use player page for a channel. This HTML page handles playback for you — embed it in an <iframe> or open it directly. The public version includes ads.

# Embed in your site
<iframe src="{{ base_url }}/api/v1/play/42"
        width="100%" height="520" frameborder="0"
        allowfullscreen scrolling="no"></iframe>

Returns 404 if the channel doesn't exist.

Private API

The private API gives you ad-free playback, higher rate limits, and is intended for production apps. Access requires an API key.

GET /api/v1/private/channels ▼

Same search, filter, and pagination as the public channels endpoint, but authenticated.

# Example
curl "{{ base_url }}/api/v1/private/channels?sport=basketball" \
  -H "Authorization: Bearer YOUR_API_KEY"
ParamTypeDescription
q, sport, source, livestringSame filters as /api/v1/channels
page, per_pagenumberPagination (default 30, max 100)
GET /api/v1/private/play/{id} ▼

Ad-free player page for a channel.

# Embed in your app
<iframe src="{{ base_url }}/api/v1/private/play/42"
        width="100%" height="520" frameborder="0"
        allowfullscreen scrolling="no"></iframe>
GET /api/v1/private/me ▼

Check the status of your API key — what it's called, its rate limit, and when it expires.

# Example
curl "{{ base_url }}/api/v1/private/me" \
  -H "Authorization: Bearer YOUR_API_KEY"

Authentication

Only the private endpoints require authentication. Send your API key as a bearer token in the Authorization header:

Authorization: Bearer YOUR_API_KEY
StatusMeaning
200Valid key, request served
401Missing, invalid, expired, or revoked key
429Key rate limit reached — slow down

Keys are hashed at rest and shown to you only once when issued. Treat them like passwords — don't ship them in client-side code that other people can see. If a key is ever compromised, reach out and it can be revoked and replaced.

Errors

The API uses standard HTTP status codes and returns a JSON error body:

// Error response
{ "error": "Stream not found." }
CodeDescription
400Invalid parameters (e.g. non-integer page)
404Channel not found
401Missing or invalid API key (private endpoints)
429Rate limit exceeded
⚠️ The public API is rate-limited per IP. If you need sustained, high-volume access, the private API is the right fit.

Getting access

The public API is open to everyone. For private, ad-free access — or if you need higher limits — reach out to the owner. Join the Discord and send a message to get set up with an API key.
